# 개발 계획

## 결정 사항
| 항목 | 결정 | 이유 |
|---|---|---|
| 실행 환경 | Google Apps Script 웹앱 | 무료, 서버 불필요, 구글 로그인·캘린더 내장 |
| 저장소 | 구글 스프레드시트 (컬렉션별 시트, 행마다 JSON) | 별도 DB 계정 없이 내 드라이브에 보관, 직접 열어 볼 수 있음 |
| 화면 | HtmlService 한 장짜리 앱 (Index.html) | 갤럭시탭 크롬 → 홈 화면에 추가 |
| 디자인 | 사이드바 + 하루 타임라인, POSCO 화이트 기준, 테마 10종 | 레이아웃 시안 1·5번을 합친 안으로 확정 |
| iCloud | CalDAV + 앱 전용 암호 | 아이폰 애플 캘린더에 실제로 저장 |
| 연동 방향 | 앱 → Google·iCloud 한 방향 | 앱이 원본. 양방향은 충돌 처리가 필요해 다음 단계로 |

## 단계
### 1단계 ✅
- [x] 대시보드(일간)·주간·월간 일정, 업무/개인 전환, 통합 검색
- [x] 일정 추가·수정·삭제, 반복·종일·알림, Google·iCloud 동시 기록
- [x] 할 일, 빠른 메모
- [x] 업무·개인 DB, 기록 추가·수정·삭제, 기록 ↔ 일정 연결, DB 항목 편집
- [x] 색상 테마 10종, 반응형(탭 가로·세로, 휴대폰)

### 2단계 (다음)
- [ ] Google 캘린더에서 직접 만든 일정 가져오기 (양방향)
- [ ] 반복 일정의 특정 날짜만 바꾸기·건너뛰기
- [ ] DB 보드(칸반)·캘린더 보기, 정렬·필터
- [ ] 기록에 파일 첨부 (구글 드라이브)
